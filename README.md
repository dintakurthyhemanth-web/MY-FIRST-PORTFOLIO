# My First Portfolio 👋

Hi! I'm **Dintakurthy Venkata Hemanth**, a first-year B.Tech student specializing in AI & ML at Quad AI. I built this repository to house my very first personal portfolio website as I work toward landing a web development internship.

## What's Inside
This project is a simple, clean single-page portfolio built from scratch using pure **HTML** and **CSS**. It includes:
* **About Me:** A quick introduction to who I am and what I'm studying.
* **Skills:** The core languages I'm currently working with (Python, C, HTML, CSS, and JavaScript).
* **Projects:** A showcase of my work, starting with a basic operations calculator.
* **Education:** My academic background from school through my current B.Tech program.
* **Contact:** Direct links to connect with me on GitHub and LinkedIn.

## How to View It
1. Download or clone this repository to your computer.
2. Double-click the `index.html` file to open it directly in any web browser.
